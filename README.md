# Saga Detective - API Backend

API desenvolvida para a disciplina de Tecnologia em Desenvolvimento de Sistemas (UTFPR - Campus Santa Helena).

## 🛠️ Tecnologias Utilizadas
- Java 21 / Spring Boot 3.x
- Spring Data JPA
- Flyway Migration
- MySQL 8.x
- Maven

## 📋 Sobre o Projeto
Plataforma interativa de investigação de crimes com gerenciamento de casos, suspeitos, pistas, depoimentos e cálculo de horas de investigação.
